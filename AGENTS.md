## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project rules

- Read `README.md` first. The section `Content rules` applies to each change.
- The site is public. Put no value of one host into a tracked file.
- The spec and the work issues live on the development tracker. The public copy does not carry the tracker.
- One topic branch for each issue: `topic/i<number>-<short-name>`. Run `npm run build` before each commit.
