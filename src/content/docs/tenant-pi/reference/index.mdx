The reference files of tenant-pi are in the project repository. This page names each file by its path. To read a file, open that path in your kit clone, for example `~/tenant-pi/docs/generator.md`.

The files of the release that this page shows are the source of facts for this site.

## Troubleshooting

This site has no troubleshooting page. The troubleshooting guide is this file of the project repository:

`docs/guides/troubleshooting.md`

The guide lists each known diagnostic with its exact text, its cause and its fix.

| Section of the guide | Content |
| --- | --- |
| How to read a diagnostic | The form `rule: field`, the key `candidate_created` and the exit codes. |
| Wiki embedding diagnostics | The refusals for the embedding choices of the `wiki` component. |
| Overlay and input | The refusals of `validate`, `plan` and `generate` for the overlay and the registry. |
| Target, private directory and launcher | The refusals for the target, for `init-private` and for the launcher file. |
| The Compose seat | The refusals of `compose-plan`, and problems with a Compose seat. |
| Comparison and carry | The refusals of `compare` and `carry`. |
| Runtime and environment | Problems with Pi, Node, `PI_CODING_AGENT_DIR` and the environment of the shell. |
| Kit checks | Failures of the publish check and of the documentation check. |
| When nothing here fits | What to keep and what to record. |

## Overlay

| File | Topic |
| --- | --- |
| `config/config.example.json` | The sample overlay. `init-private` copies it. |
| `config/manifest.json` | The manifest: each of the 27 components with its source and its status, and the key `runtime`. |
| `docs/model-routes.md` | The key `modelRoutes` and the registry. |
| `docs/owner-packages.md` | The key `ownerPackages`: a Pi package that you maintain. |
| `docs/owner-resources.md` | The key `ownerResources`: your own skills and prompts directories. |
| `docs/accepted-drift.md` | The key `unmanaged`: accepted drift. |

The key `runtime` of the manifest has these values in this release:

| Key | Value | Meaning |
| --- | --- | --- |
| `piVersion` | `1.1.0` | The Pi version that the kit tests ran on. |
| `piAcceptedRange` | `>=1.1.0 <1.2` | The Pi versions that the kit accepts. |
| `nodeRange` | `>=24.0.0 <25` | The Node versions that the kit accepts. |
| `pythonRange` | `>=3.11` | The Python versions that the kit accepts. |
